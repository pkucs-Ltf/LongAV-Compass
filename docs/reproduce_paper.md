# Reproducing Paper Aggregates

Paper aggregate analyses are computed from a sample-model metric wide table generated by your own evaluation run, for example:

```text
/path/to/best_sample_model_metrics_wide.csv
```

The full benchmark dataset, fixed QA files, generated model outputs, and result CSVs are external assets and are not included in this code repository. Download the dataset separately, run evaluation locally, and pass the resulting wide CSV to the aggregation command.

## Balanced Scores

Generate per-sample balanced scores:

```bash
PYTHONPATH=src python -m longav_eval compute-balanced \
  --input /path/to/best_sample_model_metrics_wide.csv \
  --output runs/paper/balanced_sample_model_scores.csv
```

Generate scenario-level scores:

```bash
PYTHONPATH=src python -m longav_eval compute-balanced \
  --input /path/to/best_sample_model_metrics_wide.csv \
  --output runs/paper/balanced_sample_model_scores.csv \
  --group-output runs/paper/scenario_balanced_scores.csv \
  --group-by task category model
```

The grouped `score` column is the mean balanced score of all sample-model rows in that group.

## Human Alignment

Human alignment uses three independent dimensions:

```text
content_fidelity
visual_quality
long_video_stability
```

Automatic metrics are mapped to these dimensions as described in `docs/score_definition.md`, then converted to pairwise win rates within each sample and annotator.

## Notes

- Audio metrics are reported separately and are not part of `balanced_score`.
- I2AV image-alignment metrics are reported separately and are not part of `balanced_score`.
- Scenario, event-count, and per-difficulty analyses all use the same balanced-score definition.
